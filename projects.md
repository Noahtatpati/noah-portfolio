# Portfolio Content Specification
## Version 1.0

---

# Purpose

This document defines every project that appears in the portfolio.

The portfolio must present projects as engineering case studies rather than screenshot galleries.

Each project should explain:

- The problem
- The solution
- The engineering decisions
- The technologies used
- The final product

Every project page should follow the exact same structure.

---

# Project Structure

Every project page must contain the following sections.

## Hero

Large application screenshot.

Project title.

Short description.

Project links.

GitHub

Live Demo (if available)

---

## Overview

A concise explanation of the project.

Maximum three paragraphs.

---

## Problem

Explain the real problem the project solves.

Focus on user pain points.

Avoid generic statements.

---

## Solution

Describe how the application solves the problem.

Focus on architecture and product thinking.

---

## Key Features

Present features as cards.

Each feature may contain:

- Title
- Description
- Screenshot

---

## Technical Highlights

Display technologies grouped by category.

Example

Backend

Deployment

---

## Screenshots

Every screenshot should have

Title

Short explanation

Image

No image should appear without context.

---

## Challenges

Explain engineering problems encountered.

Explain how they were solved.

---

## Lessons Learned

Discuss improvements made during development.

Mention engineering decisions.

# Project One

# TrustNow

Subtitle

National Digital Public Safety Intelligence Platform

Description

TrustNow is an AI-powered public safety platform designed to assist in detecting scams, counterfeit currency, fraud networks, and emerging digital threats through an integrated investigative interface.

Category

Generative AI

Public Safety

Cybersecurity

Status

Completed

---

## Problem

Digital fraud investigations are fragmented across multiple tools.

Citizens and investigators often need separate systems for scam detection, counterfeit analysis, fraud intelligence, and geographic threat monitoring.

This slows investigations and makes information difficult to correlate.

---

## Solution

TrustNow centralizes multiple public safety capabilities into one platform.

The application combines AI-assisted scam detection, counterfeit currency verification, geographic threat visualization, fraud network mapping, and intelligence briefings inside a unified dashboard.

# Image Guidelines

Every screenshot should

- Be displayed at high resolution.
- Open inside a lightbox when clicked.
- Preserve original aspect ratio.
- Lazy load below the fold.
- Include descriptive captions.

Never crop screenshots aggressively.

Never stretch images.

---

# Portfolio Requirements

The portfolio should feel like an engineering portfolio rather than a design showcase.

Projects should prioritize:

- Architecture
- Engineering decisions
- User experience
- Product thinking

Over visual effects.

Animations should remain subtle.

Content should always be more important than decoration.
